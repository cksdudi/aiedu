# 교육 수료관리 시스템 — 설치 및 배포 안내

정적(static) 웹사이트입니다. 별도의 서버 프로그램 없이 HTML 파일만 올리면 동작합니다.

```
edu-site/
├─ index.html          수료 현황 대시보드 (홈)
├─ learn.html          교육받기 (자료 시청 + 퀴즈)
├─ admin.html          관리자 (명단·자료·퀴즈·현황)
├─ css/style.css
├─ js/config.js        ★ 이 파일만 수정하면 됩니다
├─ js/store.js         데이터 저장 계층
├─ js/common.js        공통 UI·집계
├─ js/dashboard.js / learn.js / admin.js
├─ data/교육대상자_명단양식.xlsx
└─ firestore.rules     Firebase 보안규칙 예시
```

---

## 1단계 — 바로 열어보기 (설정 전 미리보기)

`index.html` 을 브라우저로 열면 **로컬 저장 모드**로 동작합니다.
이 모드에서는 명단·수료 기록이 **그 브라우저에만** 저장되므로 시험용으로만 사용하세요.

> 파일을 직접 더블클릭하면 브라우저 보안정책 때문에 일부 기능이 제한될 수 있습니다.
> 폴더에서 아래 명령으로 간이 서버를 띄우면 실제와 동일하게 확인할 수 있습니다.
> ```
> python -m http.server 8080
> ```
> 그 뒤 브라우저에서 `http://localhost:8080` 접속

## 2단계 — Firebase 연결 (실제 운영용 · 무료)

전 직원의 수료 기록을 한 곳에 모으려면 Firebase 를 연결합니다. 신용카드 없이 무료(Spark) 요금제로 충분합니다.

1. <https://console.firebase.google.com> 접속 → **프로젝트 만들기** (예: `edu-completion`)
   - Google 애널리틱스는 사용 안 함으로 두어도 됩니다.
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 선택
   - 모드: **프로덕션 모드**로 시작 (규칙은 4번에서 설정)
3. 프로젝트 개요 옆 **⚙ 프로젝트 설정 → 내 앱 → 웹(`</>`) 추가**
   - 앱 닉네임 입력 후 등록하면 아래와 같은 코드가 나옵니다.
     ```js
     const firebaseConfig = {
       apiKey: "AIza....",
       authDomain: "edu-completion.firebaseapp.com",
       projectId: "edu-completion",
       storageBucket: "edu-completion.appspot.com",
       messagingSenderId: "1234567890",
       appId: "1:1234:web:abcd"
     };
     ```
   - 이 값을 **`js/config.js` 의 `firebase: { ... }`** 안에 그대로 붙여넣습니다.
4. **Firestore → 규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여넣고 **게시**합니다.
5. (선택) 큰 PDF·영상 파일을 직접 업로드하려면 **빌드 → Storage** 도 활성화하세요.
   활성화하지 않으면 700KB 이하 파일만 직접 저장되고, 그보다 큰 자료는 URL 링크로 등록해야 합니다.

설정을 마치고 페이지를 열면 헤더에 **“실시간 공유”** 배지가 표시됩니다.
(“로컬 저장”으로 보이면 `js/config.js` 의 `apiKey`·`projectId` 를 다시 확인하세요.)

## 3단계 — 배포

아래 중 편한 방법을 고르세요. 모두 정적 파일 업로드 방식입니다.

| 방법 | 절차 |
|---|---|
| **기관 내부 웹서버** | `edu-site` 폴더 전체를 웹 루트(예: `/var/www/html/edu/`)에 복사 |
| **Firebase Hosting** | `npm i -g firebase-tools` → `firebase login` → `firebase init hosting` (public 폴더를 `edu-site` 로 지정) → `firebase deploy` |
| **GitHub Pages** | 저장소에 폴더 내용 업로드 → Settings → Pages → 브랜치 지정 |
| **사내 공유폴더** | 폴더째 공유하고 `index.html` 로 접속 (로컬 저장 모드로만 동작) |

## 사용 방법

### 관리자
1. `admin.html` 접속 → 초기 비밀번호 **`admin1234`** (→ 설정 탭에서 즉시 변경하세요)
2. **명단 관리** 탭
   - 엑셀 파일 선택 → 미리보기 확인 → **명단 등록하기**
   - 필요한 열: `실국`, `부서`, `성명`, `직급` (첫 행이 머리글, 순번 열은 있어도 없어도 됩니다)
   - `.xlsx` · `.xls` · `.csv` 모두 가능하며, CSV 는 인터넷이 차단된 내부망에서도 동작합니다
   - `전체 교체` / `추가·병합` 중 선택. 이후에도 개별 추가·수정·삭제 가능
3. **교육자료 · 퀴즈** 탭
   - **+ 교육자료 등록** → 제목, 설명, 자료 URL(또는 파일 업로드) 입력
   - 4지선다 퀴즈 3문항과 정답 지정 → 저장
   - `최소 시청 시간(초)` 을 지정하면 그 시간이 지나야 퀴즈 응시 가능
4. **수료 현황** 탭 — 수료자 명단 CSV 내려받기, 잘못된 기록 취소
5. **설정** 탭 — 비밀번호 변경, 전체 데이터 백업(JSON)·복원

### 교육 대상자
1. `learn.html` 접속 → 실국 → 부서 → 성명 선택 (한 번 선택하면 기억됨)
2. 교육자료 클릭 → 시청 → **퀴즈 풀기** → 3문항 모두 정답이면 즉시 수료 처리
3. 오답이 있으면 채점 결과를 보여주고 재응시할 수 있습니다.

### 수료 현황(홈)
- 상단 필터에서 **교육 과정**과 **실국**을 선택하면 모든 수치가 함께 바뀝니다.
- `전체 과정(모두 수료 기준)` 은 공개된 모든 교육자료를 이수한 사람만 수료로 집계합니다.
- 실국별·직급별 수료율 그래프, 부서별 상세표, 미수료자 명단, CSV 내려받기를 제공합니다.

## 자료 등록 요령

| 자료 형태 | 권장 방법 |
|---|---|
| 교육 영상 | 유튜브(일부공개)·비메오·네이버TV 에 올린 뒤 **주소를 붙여넣기** → 화면에 그대로 재생됩니다 |
| PDF·한글 문서 | 기관 자료실 링크 권장. 작은 PDF 는 파일 업로드도 가능 |
| 외부 교육 사이트 | 주소를 넣으면 “새 창에서 열기” 버튼이 표시됩니다 |

## 알아두실 점 (보안)

- 이 시스템은 **기관 내부용 간이 시스템**입니다. 본인 확인이 이름 선택 방식이므로
  타인 명의 응시를 완전히 막지는 못합니다. 엄격한 인증이 필요하면 행정포털 SSO 연계가 필요합니다.
- 관리자 비밀번호는 브라우저에서 확인하는 방식이라 **기술적으로 우회가 가능합니다.**
  중요 데이터를 다룬다면 사이트 자체를 내부망에만 공개하거나 Firebase Authentication 을 추가하세요.
- `firestore.rules` 는 편의를 위해 누구나 읽고 쓸 수 있도록 되어 있습니다.
  외부 인터넷에 공개한다면 규칙 파일 안의 주석을 참고해 접근을 제한하세요.
- 명단에는 개인정보(소속·성명)가 포함되므로 **가급적 내부망에 배포**하시기 바랍니다.

## 자주 있는 문제

| 증상 | 확인할 것 |
|---|---|
| 헤더에 “로컬 저장”으로 표시됨 | `js/config.js` 의 `apiKey`, `projectId` 입력 여부 |
| 엑셀 업로드 시 “머리글을 찾지 못했습니다” | 첫 행에 `실국 · 부서 · 성명 · 직급` 열 이름이 있는지 확인 |
| “엑셀 변환 기능을 불러오지 못했습니다” | 외부 인터넷이 차단된 내부망입니다. 엑셀에서 **다른 이름으로 저장 → CSV UTF-8** 로 저장한 뒤 올리면 그대로 동작합니다 |
| 수료했는데 현황에 안 보임 | 홈 화면의 **교육 과정** 필터가 다른 과정으로 되어 있는지 확인 |
| 파일 업로드 실패 | Firebase Storage 미사용 시 700KB 초과 파일은 URL 링크로 등록 |
| 유튜브 영상이 안 나옴 | 영상이 **비공개**면 임베드가 막힙니다. **일부공개(미등록)** 로 변경 |
